# 小屋世界 1.1 更新与独立选择

请安装 AI 首先阅读 [给安装 AI 的说明](../INSTALL-AI.md)。每个选项都能独立采用或保留原版；允许只更新其中几项。修复照常安装。

| 独立选项 | 更新 / 启用后 | 不启用 / 旧版 |
|---|---|---|
| 新增机器人（`add-bots`） | 可以往小屋世界里加入更多机器人，每位都有自己的房间。 | 暂不启用新增住户入口；已有住户和家保留 |
| 新版设置界面（`settings-ui`） | 设置分成 常用 / 住户 / 外观 / 音频 四页，住户用头像卡片管理。 | 保留旧设置界面 |
| 新电玩城（`arcade-renovated`） | 电玩城整体翻新：木框黄铜机台、星光地毯、分区矮墙，多一台俄罗斯方块机。 | 保留旧车站风电玩城 |
| 家具转向与新家具图（`furniture-rotation`） | 家具布置里选中家具按 R 就能转向；餐厅、小卖部、小鲸鱼家里的一部分家具换成重新画的四向版本。 | 保留旧家具图和固定朝向 |
| 五子棋（`gomoku`） | 棋桌上多了五子棋：15×15，五子连珠获胜，可以和电脑或另一位住户下。 | 暂不增加五子棋；象棋继续可用 |
| 家具工坊（`furniture-workshop`） | 自己做家具：三步填写设置、放上图片、配上机器人动作。 | 暂不启用家具工坊；已制作的家具数据保留 |
| 地图编辑器（`map-editor`） | 在设置里打开地图编辑器，可以做新的房间和户外地图，也可以改建现有房间。 | 暂不启用地图编辑器；已保存的房间和草稿不删除 |
| 新角色动作（`character-motion`） | 角色更灵动：八方向走路、坐下站起的过渡、闲着时的小动作、心情写在身上、新的思考动作。 | 保留旧角色动作 |
| 四季与节日（`seasons`） | 按真实日期分春夏秋冬，节日时房间里会有小装饰，小卖部有当季商品。 | 不增加季节装饰与当季上架规则 |
| 家旁海边（`seaside-path`） | 从小鲸鱼家南门出去，沿小路可以走到海边看海、听浪、玩沙。 | 保留原有家门路线，暂不开放海边小路 |
| 每天 50 零花钱（`pocket-money-50`） | 每天发 50 零花钱，最多存到 300（1.0 是每天 20、最多 80）。 | 保留原零花钱规则 |

现有 features.json 不会因升级被默认值重置；未回答保持当前选择。首次没有配置时可选内容先关闭，等用户逐项决定。新安装也会说明这些独立选项。

选择入口是安装 AI 的 cabin_update_plan / cabin_update_apply，或 update.cmd。离线可用 node bridge/update-cli.mjs --plan 查看机器可读清单，--list 查看说明，--set 模块id=on/off 保存，--undo 撤销上一次选择。游戏内的 1.1 模块入口已移除。

请完全关闭游戏后重启使配置生效。数据备份位于 backups/before-1.1-时间/，选择备份为 data/features.json.bak，变更回执在 data/update-receipts/。实际位置以原配置为准。不要用新包的空数据或示例配置覆盖原存档。

关闭编辑器仅隐藏功能入口，保留作品与已应用房间，不自动删除或改建。旧房间的地形改变仍需要在地图编辑器主动应用，不因安装本包自动装修。
