# 提案 · 外部住户画面和宿主对话

这是一份供维护者审阅的接口提案。目标是让 Figure Scape 使用 Cabin World 的官方发行包，同时保留现有适配的用户体验。它也应能服务其他通过公开接口接入小屋世界的宿主。

## 背景

Cabin World 1.1 的官方桥已提供住户登记、场景状态、行动、家具、餐厅、电玩城和任务回执等能力。Figure Scape 目前还为游戏加载了额外的 Godot 脚本，用于把实时角色画面接到住户、显示宿主会话，以及调整部分侧栏。希望把这些行为提炼为可选的官方能力，以便使用官方发布的游戏和配套桥。 [官方 HTTP 接口](../HTTP-API.md) · [现有协议](../PROTOCOL.md)

## 职责边界

| 领域 | Cabin World | 外部宿主（以 Figure Scape 为例） |
| --- | --- | --- |
| 住户和玩法 | 登记稳定住户 ID，保存房间、位置、背包和存档，执行动作并结算 | 绑定自己的角色 ID 与游戏住户 ID，调用官方工具，依据任务回执和事件回应 |
| 实时角色画面 | 把外部透明画面绘制到对应住户，使用游戏自己的朝向、遮挡和放置规则。断开后恢复游戏外观 | 提供头像、最新透明帧和必要的锚点、缩放信息。负责角色原始模型和渲染 |
| 游戏内对话 | 在原生侧栏提供可选聊天页，展示输入、等待、失败和消息列表 | 处理输入、去重、历史和回复。Figure Scape 接续已有 Coo 会话 |
| 侧栏和原生功能 | 负责住户选择、改名、房间管理、活动区及电玩城战绩的界面和真实数据 | 提供当前选定的住户和宿主连接状态 |
| 开窗和重连 | 报告住户位置就绪、外部画面应用和窗口可见等实际状态 | 负责启动来源、连接恢复、场景切换与错误提示 |
| 像素住户反向导入 | 提供官方允许导出的素材清单和署名信息 | 读取方向、帧序列和锚点，生成自己角色库的条目与封面 |

## 能力和兼容

- 复用配套官方桥的连接和能力发现方式。住户、任务、对话请求以稳定 ID 关联。已在官方桥提供的游戏动作仍通过原工具执行，结果继续由游戏产生。
- 外部画面按住户和连接会话绑定。头像与连续帧可分别更新。游戏只保留当前需要的画面，掉线、换住户和重新连接都有明确的回收语义。新连接获取独立身份，旧画面无法覆盖新住户。
- 对话接口区分读取记录、提交、宿主接受、拒绝和回复。失败后保留输入，重试沿用同一请求 ID。切换住户或宿主掉线时，旧回执继续结算自己的请求。
- 侧栏沿用原版住户和战绩组件。建议将当前住户标识、重名时的区分、刷新住户和进入当前住户管理做成原生能力。电玩城的活动与历史结果继续用游戏自己的比赛记录呈现。
- 安装以官方发行包和配套桥为单位。现有住户编号与存档用于迁移验证。素材导出与店员外观选项由上游根据已有发布规则决定。
- 新接口可协商、可缺省。普通官方启动、原生住户和 AstrBot、DeepSeek Harness 的既有接入继续按各自的实际用例验收。

## 可按组评审的实现范围

1. 定义可选能力和住户生命周期，提供独立最小宿主示例。
2. 接入外部渲染、头像和断连恢复，并通过等待画面应用的用例。
3. 接入通用对话页和宿主回执，完善住户侧栏与电玩城显示。
4. 提供住户素材清单和官方接入文档，再核对 Figure Scape 迁移。

## 功能对照及验收

| 用例 | 可观察结果 |
| --- | --- |
| 连接配套官方包，选两个不同住户 | 住户名、房间与状态准确。重连后仍能识别同一住户，未确认的操作保持原状态 |
| 用外部头像和动画行走、入室、坐下 | 图片、脚点和遮挡正确。断开后恢复官方住户外观，其他住户照常显示 |
| 在游戏内发消息、失败重试、切换住户 | 发送状态准确，一次请求只入历史一次，回复落在原会话，滚动和草稿可恢复 |
| 走路、使用家具、购物、餐厅、电玩城 | 复测现有 14 项 Figure Scape 工具声明，以及配套桥的版本和能力选择。实际动作、取消、完成和结算与游戏记录一致 |
| 住户与历史侧栏 | 重名住户可以区分，当前住户可直达管理，多个住户及电玩城历史仍可读 |
| 退出、崩溃、重新打开及重新连接 | 允许游戏和宿主分别处理自己的生命周期。原住户与存档可读，已提交的购买与结算保持一次 |
| 从官方素材导入像素住户 | 方向、动画与锚点正确，生成的封面和署名完整，重复导入识别原角色 |
| 原有宿主回归 | 使用官方 Windows 包分别验证普通启动、AstrBot 和 DSH 接入 |

完成以上实测后，Figure Scape 可把日常入口切换为作者发布的原始 ZIP，逐项保留现有功能。当前提交供接口与职责评审，实装与官方包验收将作为后续提交。
